    About the browser test

    • Speed test finds the most this link carries: it measures the idle latency, then downloads as fast as possible over several TCP connections, then uploads. The first seconds of each phase (TCP ramp-up) are left out of the result. Latency is measured all along: how much it rises while downloading or uploading is the bufferbloat. The result is capped at the server's limit per direction.
    • Network test runs a speed test, then the parts you tick, one after the other: TCP, UDP-style and mixed load at a share of the speed you measured (80% by default, so loss and jitter show the link rather than a full queue), and a video call, a VoIP call and gaming at their own rates. The SNMP test can run alongside every part. Each part is saved as its own test, with its own report.
    • UDP-style traffic runs over a WebRTC data channel set to unreliable and unordered: real UDP packets, real loss and jitter. WebRTC adds congestion control, so when the link is overloaded you may see lower throughput rather than heavy loss. Browsers handle up to 25 Mbps each way this way; for higher rates use TCP (a mixed test sends the rest as TCP). The server needs UDP reachable.
    • TCP runs over WebSockets: throughput and round-trip time; TCP hides packet loss by retransmitting, so loss isn't measured.
    • SNMP test polls the server once a second and sends it an inform every 5 s, with an SNMP manager's timers (1 s timeout, 5 retries): whether the answers come back, how fast, and how many need retries. Browsers can't send SNMP and refuse WebRTC connections to ports below 1024, so the page can't use SNMP's own ports (UDP 161 and 162): it uses the server's browser SNMP ports, UDP 1161 and 1162, over WebRTC. For real SNMPv2c to UDP 161 and 162, use the LinkTest apps.
    • Keep this tab in the foreground during a test: browsers slow down background tabs, which would show up as gaps and lower upload rates.
    • The HTTPS page encrypts the connection, including the server key.
    • Not available in a browser — use the LinkTest apps for these: DSCP marking and the DSCP traffic mix, VPN tunnel simulation, path MTU, traceroute, the capacity test, IPv4 vs IPv6 comparison and TCP retransmit counts.
