LinkTest server - third-party software
======================================

The LinkTest server programs (LinkTestServer.exe, LinkTestServerGui.exe) include the following
third-party components for browser tests. Each is used unmodified under its own licence.

DataChannelDotnet (.NET bindings for libdatachannel)
  https://github.com/ZetrocDev/DataChannelDotnet
  Licence: MIT

libdatachannel (WebRTC data channels), with libjuice (ICE)
  https://github.com/paullouisageneau/libdatachannel
  https://github.com/paullouisageneau/libjuice
  Licence: Mozilla Public License 2.0 (https://mozilla.org/MPL/2.0/).
  The source code of these libraries is available at the addresses above.

usrsctp (SCTP)
  https://github.com/sctplab/usrsctp
  Licence: BSD 3-Clause

libsrtp
  https://github.com/cisco/libsrtp
  Licence: BSD 3-Clause

plog (logging)
  https://github.com/SergiusTheBest/plog
  Licence: MIT

OpenSSL 3 (TLS / DTLS)
  https://www.openssl.org/
  Licence: Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0)

.NET and ASP.NET Core (Kestrel web server)
  https://github.com/dotnet/runtime, https://github.com/dotnet/aspnetcore
  Licence: MIT
